Синтаксис кубиков ​

Поддерживаемый синтаксис калькулятора вероятностей.

Основы программы ​

Программа состоит из инструкций. Переменные — это слова заглавными буквами, им присваивается значение через двоеточие. output добавляет результат, а named задаёт ему название.

text
X: 3
output X + 1 named "four"

DAMAGE: 2d6 + 3
output DAMAGE named "sword damage"
  • Комментарии выделяются обратными слэшами: \ это игнорируется \
  • Переменные можно переприсваивать; они вычисляются по порядку.
  • 0 — это ложь; любое другое число — истина.
  • В названиях output поддерживается подстановка [ПЕРЕМЕННАЯ], например named "ability [P]".

Числа, кубики и операторы ​

СинтаксисЗначениеПример
+ - * /Арифметика. Целочисленное деление округляется к нулю.output 2d6 + 3
^Возведение в степень с неотрицательным целым показателем.output 2 ^ 3
= != < > <= >=Сравнение. При применении к кубикам даёт кубик из 0 и 1.output 3d6 >= 15
& | !Логические и, или и не. Ноль — ложь, любое другое число — истина.output 1d6 > 3 & 1d6 != 6
@Доступ по позиции в последовательности, наборе кубиков или цифрах числа.output 1@3d6
#Длина последовательности или набора кубиков; количество цифр числа.output #(3d6)
dСоздаёт кубик или набор кубиков.output 4d6
..Включающий диапазон внутри литерала последовательности.{1..6}
:Количество повторений и разделитель имени переменной и значения.{1:4}, X: 3

d6 — один шестигранный кубик, 3d6 — набор из трёх кубиков, которые суммируются, d% — это d100. Свои кубики задаются последовательностью, например d{1,2,4,4}. Грани может задавать любое выражение, например 2d(1d4). Пустой кубик записывается как d{}.

Последовательности ​

Последовательности записываются в фигурных скобках. Они сохраняют порядок записи; чтобы применить настройку порядка позиций, используйте sort. Математические и логические операции суммируют все элементы последовательности.

text
{1, 2, 3}
{1..6}
{1:4, 2, 3}
{1..3:2}
{{1,2,4}:2, 5, 6}
{d6}
{}

Позиция и длина ​

text
1 @ {2,4,6}    \ 2 \
3 @ {2,4,6}    \ 6 \
{1,3} @ {2,4,6} \ 8 \
# {2,4,6}      \ 3 \
1 @ 246        \ 2 \
# 1234         \ 4 \
# (3d6)        \ 3 \
{1,2} @ 3d6

set "position order" to "lowest first" меняет порядок позиций кубиков и цифр. Литералы последовательностей не переупорядочиваются, пока не применён sort.

Циклы и условия ​

text
loop N over {1..4} {
  output Nd4 named "[N]d4"
}

X: 1
if X = 1 {
  output 1
}
else if X = 2 {
  output 2
}
else {
  output 1d6
}

В условиях можно использовать сравнения и логические операторы. Поддерживается else if. Кубик нельзя напрямую использовать как условие if; передайте его функции с типизированным параметром. Циклы перебирают значения последовательности или кубика.

Функции ​

Имена функций состоят из слов строчными буквами и переменных-параметров заглавными. Функция вызывается именем и аргументами в квадратных скобках. Функция завершается при result:; без result она возвращает пустой кубик.

text
function: add A to B {
  result: A + B
}

output [add 1 to 2]
output [add d4 to d6]

Типы параметров определяют преобразование значений. Параметр без типа получает значение без преобразования:

  • :n — числа. Последовательность суммируется; кубик раскрывается по каждому исходу.
  • :d — кубики. Число становится постоянным кубиком; последовательность суммируется и становится постоянным кубиком.
  • :s — последовательности. Число становится последовательностью из одного элемента; кубики раскрываются во все возможные отсортированные броски.

Функции могут быть рекурсивными. Максимальная глубина задаётся через set "maximum function depth" to N. output и set внутри функции запрещены.

Библиотека функций ​

ФункцияЗначение
[absolute NUMBER]Абсолютное значение.
[SEQUENCE contains NUMBER]1, если число встречается в последовательности, иначе 0.
[count VALUES in SEQUENCE]Считает вхождения; повторяющиеся значения считаются несколько раз.
[explode DIE]Продолжает бросок при выпадении максимального значения.
[highest N of DICE]Сумма N наибольших значений. Поддерживает несколько наборов через and.
[lowest N of DICE]Сумма N наименьших значений. Поддерживает несколько наборов через and.
[middle N of DICE]Сумма N средних значений.
[highest of A and B]Большее из двух чисел; кубики раскрываются по каждому исходу.
[lowest of A and B]Меньшее из двух чисел; кубики раскрываются по каждому исходу.
[maximum of DIE]Наибольшее возможное значение кубика (0 для пустого кубика).
[minimum of DIE]Наименьшее возможное значение кубика (расширение движка).
[reverse SEQUENCE]Обращает порядок последовательности.
[sort SEQUENCE]Сортирует с учётом настройки порядка позиций.

Настройки ​

text
set "position order" to "highest first"
set "position order" to "lowest first"
set "explode depth" to 2
set "maximum function depth" to 5

Настройки применяются к следующим за ними инструкциям. По умолчанию используется порядок от наибольшего к наименьшему.

Примеры ​

4d6 без худшего ​

text
output [highest 3 of 4d6] named "4d6 drop lowest"

ABILITIES: 6 d [highest 3 of 4d6]
loop P over {1..6} {
  output P @ ABILITIES named "Ability [P]"
}

Blades in the Dark ​

text
function: blades ROLL:s {
  if 1@ROLL = 6 {
    result: 2 + (2@ROLL = 6)
  }
  result: 1@ROLL >= 4
}

output [blades 2d6] named "0d"
loop P over {1..7} {
  output [blades Pd6] named "[P]d"
}

Взрывающиеся кубики ​

text
set "explode depth" to 3
output [explode d6] named "one exploding d6"
output 2d[explode d6] named "two independent exploding dice"

Функции и приведение типов ​

text
function: double N:n if above B:n {
  if N > B { result: N + N }
  result: N
}

output [double d6 if above 3] named "1, 2, 3, 8, 10, 12"

function: ROLL:s count fives and above and subtract ones {
  result: (ROLL >= 5) - (ROLL = 1)
}

output [3d6 count fives and above and subtract ones]
