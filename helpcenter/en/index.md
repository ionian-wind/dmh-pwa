Welcome to the Owlbear's DMH help center.

This is a static VitePress site. The app's **Help center** menu item opens this
localized landing page in a new tab, and **Open app** in the top navigation
returns to the app. Use the language menu to switch to Russian. Local search is
available from the navigation bar.
