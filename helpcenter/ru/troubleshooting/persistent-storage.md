# Постоянное хранилище

Owlbear's DMH хранит данные кампании локально в браузере. Постоянное хранилище —
это рекомендация браузеру не удалять данные автоматически при нехватке места.

Решение принимает браузер. Он может отказать сайту, который не установлен, редко
используется или открыт в приватном окне.

![Настройки сайта в браузере](images/site-settings.svg)

## Chrome и Edge

1. Сначала [установите приложение](../getting-started/install.md). Установленным
   приложениям браузер чаще предоставляет постоянное хранилище.
2. Откройте панель сведений о сайте по значку слева от адресной строки и
   проверьте **Настройки сайта**.
3. Убедитесь, что cookies и данные сайта разрешены.
4. Вернитесь в **Настройки → Данные → Постоянное хранилище** и запросите его
   снова.

В Chrome и Edge нет отдельного переключателя «постоянное хранилище». Браузер
предоставляет его автоматически с учётом установки и активности, поэтому
установка приложения и обычное использование — надёжный путь.

## Firefox

Firefox может показать запрос, когда сайт просит постоянное хранилище. Если
разрешение было заблокировано, откройте сведения о сайте, проверьте разрешения и
попробуйте снова. Также можно проверить настройки сохранённых данных сайтов в
браузере.

## Safari

Safari управляет хранилищем отдельно для каждого сайта. Проверьте настройки
хранилища сайта в адресной строке или в настройках Safari. На iOS откройте
**Настройки → Safari → Дополнения → Данные сайтов**.

## Если браузер всё равно отказывает

- Установите приложение и открывайте его из установленной записи.
- Пользуйтесь приложением некоторое время, затем запросите постоянное хранилище
  снова.
- Перед очисткой данных браузера или изменением настроек сайта сохраните
  актуальную резервную копию.
