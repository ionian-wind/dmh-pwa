# Форматирование Markdown

## Внутренние ссылки

Ссылайтесь на другие сущности кампании через `[название](тип://id)`:

- `[Название заметки](note://123)` — ссылка на заметку
- `[Название модуля](module://123)` — ссылка на модуль
- `[Название группы](party://123)` — ссылка на группу
- `[Название монстра](pawn://123)` — ссылка на монстра
- `[Название схватки](encounter://123)` — ссылка на схватку

## Упоминания сущностей

Используйте кнопки упоминаний на панели редактора, чтобы связать заметку,
модуль, группу, монстра или схватку. Упоминания используют тот же синтаксис
внутренних ссылок:

`[Таверна](note://123)` упоминает заметку «Таверна».

## Теги

Введите `#` в редакторе, чтобы найти или создать тег, либо напишите хештег
вручную. Теги собираются в меню параметров заметки.

- `#tavern` добавляет тег «tavern».
- `# Заголовок` заголовки вроде этого не считаются тегами.

## Markdown

Базовое форматирование Markdown:

| Синтаксис                       | Результат                 |
| ------------------------------- | ------------------------- |
| `**жирный**`                    | **Жирный текст**          |
| `*курсив*`                      | _Курсив_                  |
| `# Заголовок`                   | Заголовок раздела         |
| `- пункт`                       | Маркированный список      |
| `1. пункт`                      | Нумерованный список       |
| `- [ ] Задача` / `- [x] Готово` | Список задач с чекбоксами |

Списки задач, записанные как `- [ ]` или `- [x]`, отображаются как неактивные
чекбоксы.
